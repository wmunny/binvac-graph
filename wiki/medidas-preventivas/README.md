# Catálogo de medidas preventivas

Catálogo reutilizable de medidas. Cada medida indica su **jerarquía** (art. 15
LPRL), el ámbito, las causas que ataca y las fichas de origen. Al investigar un
accidente nuevo, reutiliza estas medidas y adáptalas.

Prioridad (de mayor a menor): eliminación → sustitución → ingeniería/colectiva →
organizativa → EPI.
